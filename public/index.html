결과 저장

사진 처리와 결과의 한계

원본 사진은 업로드 시 EXIF 등 메타데이터를 제거한 PNG로 변환합니다. 백엔드는 얼굴·체형·포즈·손·배경을 유지하고 의류의 색·패턴·로고·재단을 보존하도록 지시합니다. 이 지시는 보존을 보장하지 않습니다. 결과를 원본과 직접 비교하세요.

결과는 AI가 만든 외형 미리보기이며 실제 사이즈나 착용감을 측정하지 않습니다. MAI는 Preview이며 프로덕션 사용을 권장하지 않습니다. 현재 모델 품질과 실제 API 호환성은 클라우드 검증 전입니다.

서버에는 사진을 파일로 저장하지 않습니다. 결과는 서버 메모리에 완료 후 최대 10분 보관하며 접속 세션은 30분 후 만료됩니다. 비우기를 누르면 서버 결과와 브라우저 미리보기를 제거합니다. 진행 중 요청을 중단해도 Azure 처리나 과금 취소를 보장하지 않습니다. Azure 자체 데이터 처리 정책은 별도로 적용되며 Global 배포는 리소스 지역 밖에서 처리할 수 있습니다.

아직 생성한 결과가 없습니다.

Azure 관리 모델만 사용합니다. 연결 상태는 설정 확인 결과이며, 모델의 배포 가능 여부나 품질 검증 결과가 아닙니다.
