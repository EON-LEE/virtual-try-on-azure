사진은 제출 전까지 이 브라우저에서만 미리 봅니다. 제출하면 EXIF 방향 반영·메타데이터 제거 PNG를 선택한 Azure 모델에 전송합니다. 결과와 원본은 크기나 비율이 달라질 수 있으며 잘라 맞추지 않고 전체를 표시합니다. 사진을 클릭해 확대할 수 있습니다.

이전 실험의 사전 평가는 이 화면의 새 결과에 적용하지 않습니다. 각 결과 아래 수동 평가는 브라우저 메모리에만 있으며 업로드·새 생성·비우기·새로고침 시 사라집니다. 자동 품질 점수나 통과 판정을 생성하지 않습니다. 실제 사이즈·착용감 예측이 아니며 MAI Preview는 프로덕션에 권장하지 않습니다.

서버 사진 파일 저장 없음. 결과는 완료 후 최대 10분, 세션은 최대 30분 보관합니다. 단일 인스턴스 데모는 재시작·축소 시 결과와 세션이 사라집니다. 비우기는 이미 수락된 Azure 처리·과금 취소를 보장하지 않습니다. Global 모델 배포는 리소스 지역 밖에서 처리할 수 있으며 Azure 자체 정책은 별도로 적용됩니다.

새 결과에는 자동 평가를 붙이지 않습니다.
