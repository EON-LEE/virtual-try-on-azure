# 국내 브랜드 6조합 후보: 사용권리 확인 전

**2026-10-15 정정:** 아래는 폐기 이전의 조사 기록이다. 기존 인물사진과
그 사진이 내장된 HTML/preview는 사용자 지시로 폐기했다. 기존 조합은 철회했으며
재사용하지 않는다. `report.py`는 이제 이미지 없는 신규 시작 화면만 생성한다.
신규 2026 시즌 상품/새 인물/사진 사용권리 확인과 진행 확인 전 호출은 중지한다.
현재 상태와 폐기 근거는 `photo-reset.md`, `restart-state.json`을 따른다.

## 확보한 것과 확보하지 못한 것

2026-10-14 공식 원문 조사 기준으로 **빈폴·에잇세컨즈·헤지스의 3개 브랜드,
삼성물산·LF의 2개 회사** 상품 6개를 다음 실험 후보로 고정했다.
`brand-cases.json`에는 실제 상품 ID, 공식 URL, 소재 확인 범위, 인물 파일 ID/해시,
포즈, 평가 항목, 권리 상태를 기록했다.
일반 데이터셋 의상을 국내 브랜드 상품으로 표시하지 않았다.

아직 **사용 가능한 브랜드 의상 사진 6개는 확보하지 못했다**.
브랜드 사진의 권리를 확인하지 않은 상태에서 내려받기·AI 편집·Azure 전송을 진행하지 않았다.
인물 사진은 기존 로컬 VITON-HD 입력 2개와 같은 pinned mirror에서 추가 확보한
`image/00683_00.jpg` 1개를 후보 preview에만 표시한다.
추가 파일은 현대 컬러 실제 사진이며, 양손이 몸통 앞에서 만나는 자세를 육안으로 확인했다.
팔 교차보다 가림이 적은 비교 조건이다. 원본 해시와 비상업 권리 한계는 manifest에 기록했다.
이것은 새 Azure 전송 승인이나 정확한 새 배치 scope 고정을 뜻하지 않는다.
의상 사진·해시가 없는 후보는 실제 실험 입력 완료로 계산하지 않는다.

## 권리 조건을 회사별로 확인

[삼성물산 SSF SHOP 약관](https://www.ssfshop.com/public/common/information/termsAndConditions)
제21조와 [LF 헤지스 약관](https://www.hazzys.com/display.do?cmd=getUseClause)
제25조는 각각 회사/몰이 작성한 저작물의 권리를 회사/몰에 귀속시킨다.
두 조항은 사전 승낙 없는 영리 목적 이용 또는 제3자 이용을 제한한다.
**비상업 AI 편집·Azure 전송 허용을 명시한 라이선스는 발견하지 못했다.**
이를 모든 비상업 참고까지 금지한다고 확대 해석하지 않으며,
반대로 비상업이라서 사진 복제·외부 처리 권한이 자동 발생한다고 해석하지 않는다.
현재 판정은 양사 모두 ‘링크 후보만, 해당 사용권리 미확인’이다.

한섬의 공식 상품·고객센터와 신세계의 공식 진입점도 검토했다.
확인된 한섬 홈 상의 일부는 수입 MEIMEIJ였으므로 국내 브랜드 수에 넣지 않았다.
검토한 자료에서 이번 사용을 명시적으로 허용한 공식 presskit/연구용 배포 사진은 확보하지 못했다.
이는 모든 브랜드의 모든 자료를 전수 조사했다는 뜻이 아니다.
마케팅용 자료의 공개 열람 역시 연구 편집 허가로 추정하지 않는다.

사진 권리자에게 **비공개 비상업 실험, Azure 처리, 입력과 생성 결과의 로컬 보관,
재배포 없음**을 설명하고 허락 범위를 받아야 한다.
SSF SHOP 공식 고객센터(1599-0007) 또는
[헤지스 공식 고객센터](https://www.hazzys.com/customer.do?cmd=getFaq)에서
상품 사진 권리자/홍보 담당자에게 연결을 요청할 수 있다. 연락은 보내지 않았다.
대안은 사용자가 보유한 해당 브랜드 옷을 직접 촬영하고 정확한 사진 사용권리를 확인하는 것이다.
직접 촬영은 타인 촬영물의 권리 문제를 줄이지만 모든 브랜드·디자인 권리를 자동 해결하지 않는다.

## 통합 이미지 보고서

`local\report\index.html`은 기존 **16회 시도/11개 실제 출력/5회 실패**와
새 6조합 후보를 합친 self-contained 보고서다.
출력 성공과 엄격 보존 통과를 구분하며, 과거 pilot pass 2개를 현 엄격 기준 pass로 바꾸지 않는다.
기존 이미지와 후보 인물은 큰 4열에서 원본 종횡비를 유지하고 클릭/Enter로 확대한다.
필터는 실제 실험/미실행 후보/팔 교차/팔 올림/기타 포즈를 구분한다.
권리·학계 근거·GT 한계·usage·조건부 estimate·실청구 미확인은 접힌 상세에 있다.
의상 사진이 미확보인 셀에는 권리 확인 전 상태와 공식 상품 링크만 넣는다.
이 상태를 여섯 개 완성 입력 사진 비교라고 주장하지 않는다.

재생성은 네트워크 없는 로컬 명령이다:

```powershell
python .\experiments\report.py
```

보고서는 외부 이미지를 로드하지 않으며 CSP에서 네트워크 연결을 차단한다.
사용자가 명시적으로 상품 링크를 누르면 공식 사이트가 새 탭에서 열릴 수 있다.
사진과 HTML은 ignored local에만 저장한다. Git에는 생성기·manifest·문서만 보존한다.
`local\report\candidate-input-preview.jpg`도 제공한다.
6행의 실제 인물 사진 옆에 의상 사진 미확보 상태를 표시한 미완성 입력 preview이며,
그 빈칸을 제품 생성 이미지나 다른 옷으로 채우지 않았다.
이 작업에서는 추가 Azure 전송/추론/권한/배포/호스팅 변경이 모두 0회다.
다음 호출은 사진 사용권리, 정확 입력 bytes/해시, 모델별 호출 수를 별도로 승인한 뒤에만 가능하다.
