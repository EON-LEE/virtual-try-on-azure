# 실제 브랜드 의상과 어려운 포즈의 다음 실험 후보

**2026-10-15 상태 변경:** 기존 사진 및 파생 이미지 HTML은 폐기했다.
아래의 과거 인물·의상 조합은 다시 사용하지 않는다. 학계 검증 항목과
공식 상품 링크/권리 조사는 참고 기록으로만 유지한다.
신규 입력과 진행 조건은 `photo-reset.md`, `restart-state.json`을 따른다.

## 결론과 실행 범위

2026-10-14에 삼성물산 SSF SHOP 공식 상품 원문과 상품 구조화 데이터를 확인했다.
체크·코듀로이·프린트·자수를 구분해서 검사할 수 있는 상의 후보 5개를 찾았다.
이번 조사는 **상품 링크와 평가 항목 선정**이다. 상품 사진의 AI 편집 또는 Azure 전송을 허가받은 것은 아니다.
상품 사진은 내려받거나 재배포하지 않았으며, 새 추론·배포·권한 변경은 하지 않았다.
기존 유료 호출 승인은 16회 모두 소진됐다.

먼저 **큰 멀티체크 + 팔 교차**, **코듀로이 체크 + 올린 팔**을 추천한다.
이는 다음 입력 조합 제안이며 승인된 실행 계획이 아니다.
브랜드 사진 사용권리를 확보한 뒤 정확한 입력 파일·해시·호출 수를 별도로 승인해야 한다.
기존 VITON-HD의 비상업 조건은 브랜드 상품 사진의 권리를 대신하지 않는다.

### 상품 사진 사용조건

[SSF SHOP 공식 이용약관](https://www.ssfshop.com/public/common/information/termsAndConditions)
제21조는 회사 작성 저작물의 권리를 회사에 귀속시키고, 회사 권리 정보의 사전 승낙 없는
영리 목적 이용 또는 제3자 이용을 제한한다. 이를 비상업 AI 편집·클라우드 전송의 명시 허용으로
해석하지 않는다. 검토한 약관·상품 페이지에서 해당 용도를 명시적으로 허용하는 라이선스는 찾지 못했다.
비상업이라는 이유만으로 모든 사용이 금지라고 단정하지도 않는다. 현재 상태는 **사용권리 미확인·링크 후보만**이다.

대안은 상품 사진 권리자의 허락, 또는 사용자가 보유한 옷을 직접 촬영한 사진이다.
직접 촬영하면 타인의 상품 촬영 저작권 문제를 줄일 수 있지만 브랜드·디자인의 모든 권리까지
자동 해결하지는 않는다. 인물 사진은 성인 여부와 촬영·편집·전송 동의를 별도로 확인해야 한다.

| 재단·부품·겹침 | 카라/버튼 셔츠, 래글런, 레이어드 저지 | 보이는 카라 끝·소매 봉제선·단추 수/순서·밑단을 체크리스트로 비교. 각 레이어의 경계를 검사하고 손/옷의 앞뒤 관계와 함께 판정 | 기존 neckline/sleeve/hem 육안 실시; 새 버튼/레이어 미실시 |
| 드러난 피부 | 긴소매 원본→반소매 목표 | 원본에서 이미 보이는 피부의 보존과 새로 드러난 부분을 별도 표기. 새 피부의 자연스러움은 관찰할 수 있으나 실제 피부·문신·근육 형태의 정확성을 검증했다고 하지 않음 | 새 팔 피부를 검증 불가로 명시; 추가 GT 없음 |
| 자연스러운 착용 | 모든 포즈·의상 | 주름·소매 연결·가림이 보존한 자세와 양립하는지 육안 판정. 손 이동으로 자연스러움을 만들어낸 결과는 실패 | 육안 실시; 사이즈·물리 fit 예측 아님 |

### ground truth와 지표의 한계

VITON-HD §4.1/4.3과 TPD §4의 paired 조건은 **원래 입던 같은 옷의 재구성**이다.
unpaired는 다른 옷으로 바꾸는 조건이다. 이번 cross-pair는 정확한 착용 ground truth가 없다.
따라서 참조 의상 플랫 사진과 출력 사이의 SSIM/LPIPS를 실제 착용 품질 점수로 만들지 않는다.
실제 같은 인물이 목표 옷을 같은 자세로 입은 정답 사진을 확보해도 재촬영·정렬·조명 차이를 보고해야 한다.

FID는 이미지 집단의 분포 지표이며 이 두 조합/네 결과로 개별 로고·손·질감 보존을 증명하지 않는다.
낮은 FID나 보기 좋은 사진이 사용자 요구의 pass를 대신할 수 없다.
브랜드 이미지 권리와 사진 전송 승인을 해결하지 않은 상태에서 지표 확보를 위해 추가 호출하지 않는다.

## MAI 상위 tier의 정확한 범위

`azure-evidence.md`의 2026-10-14 공식 guide 및 명시 구독의 East US catalog 조사:
`MAI-Image-2.5-Pro`, version `2026-06-19`, Preview, image edit 지원,
GlobalStandard quota current 0 / limit 2 RPM.
이는 요청 처리 보장이나 즉시 접근·배포 성공 증거가 아니다.
공식 설명은 **2.5 시리즈의 최고 품질**이며 현재 `MAI-Image-2.6`
version `2026-07-31`보다 VTO 품질이 좋다는 비교 증거는 없다.
2.6-Pro/Ultra는 조사 목록에서 발견하지 못했다. Flash는 속도·비용 variant다.

[공식 MAI guide](https://learn.microsoft.com/en-us/azure/foundry/foundry-models/how-to/use-foundry-models-mai-image)는
`/mai/v1/images/edits`와 최대 5개 이미지 참조를 문서화한다.
Pro의 mask/input-fidelity 제어는 확인하지 못했고,
`auto_aspect_ratio`/`web_grounding`는 조사 guide에서 2.6/2.6-Flash에 한해 문서화돼 있다.
정밀 편집 지원과 포즈·로고·질감 보존의 성능 보장은 다르다.
공식 token list meters와 접근 한계는 `azure-evidence.md`에 유지한다.
Pro를 배포하거나 호출하지 않았다.
